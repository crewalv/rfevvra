# Торос — Энергия арены

Демонстрационный сайт хоккейного клуба «Торос», Нефтекамск. Это презентация нового сайта, а не официальный ресурс клуба.

## Запуск

Node.js 22 или новее. `npm ci`, затем `npm run dev`.

`npm run lint` — ESLint. `npm run build` — TypeScript, сборка Vite, статический fallback. `npm run preview` — локальный просмотр сборки.

## Разделы

- `/` — главный экран, Rubber Segment для категорий новостей, ближайший матч, команда и школа.
- `/team` — 26 игроков основного состава, фильтры, поиск и профили. `/team?tab=coaches` — три тренера.
- `/calendar` — список и календарная сетка, месяцы, фильтры дома/на выезде, карточки встреч, экспорт игры в ICS.
- `/club` — история, чемпионские годы, адрес и контакты.
- `/news` и `/news/:slug` — четыре публикации, фильтры и поиск.
- `/tickets` — переход в билетный сервис, информация о доступности, вопросы и ответы.
- `/school` — информация для родителей, вопросы и ответы, скачиваемая памятка.
- `/about-demo` — источники и границы демонстрации.

## Данные

Спортивные сведения — снимок источников на 05.11.2026, не живая интеграция. В календаре три проверенные встречи, не весь сезон. Данные отделены от UI в `src/data/content.ts`. Результаты, цены, портреты и биографии не выдумываются. Для недостающих портретов предусмотрены явные места под материалы клуба. Баннеры основаны на реальных фотографиях, предоставленных владельцем проекта: выполнены художественная обработка, расширение фона и лёгкая ледяная фактура. Оригиналы сохранены владельцу отдельно; пути к фотографиям централизованы в `src/data/media.ts`. Фотографии публикаций имеют указанные источники.

Оплата, приём персональных данных, редактор и отправка заявлений отсутствуют. Кнопки не показывают фиктивный успех.

## Основа интерфейса

React, TypeScript, Vite, React Router. Меню, диалоги, панели, вкладки и карточки — shadcn/ui на Radix UI. Карусель — Swiper. Rubber Segment — официальный исходник React Bits, версия из коммита `4dc7b5b7772e1217c8fb8d2a7aa074302180e5b4`. Цвета и размеры адаптированы, поведение сохранено. Шрифты Manrope и Roboto Condensed 900 Italic размещены локально. Лицензии и происхождение: THIRD_PARTY_NOTICES.md и component-provenance.json.

## Локальная проверка живых фотографий

Три первых слайда используют движение цельной фотографии за курсором и частицы React Bits. Первоначальная деформация через карту глубины удалена после обнаружения разрывов шлема и плеча: игрок и фон теперь перемещаются вместе, без изменения формы фотографии. Режим согласован владельцем 05.11.2026 для локального просмотра, без публикации, push и commit до оценки результата. Исходные фотографии сохранены. Размер фотографии имеет запас для плавного смещения; текст и управление остаются неподвижными.

Движение работает только в активном видимом слайде и останавливается при скрытии вкладки. Кнопка паузы удалена по поручению владельца; системное уменьшение движения отключает оба эффекта. При недоступном WebGL остаётся исходная фотография. Каждый эффект ограничен 30 fps; размеры canvas ограничены по плотности пикселей, GPU-ресурсы освобождаются при выключении. Лицензии и закреплённые версии записаны в THIRD_PARTY_NOTICES.md и component-provenance.json. Протокол локальной проверки: `../reports/2026-11-05/living-photos/`.

## GitHub Pages

Репозиторий: https://github.com/Denis824-lab/toros

Публикация выполняется GitHub Actions после push в main. Для Pages сборка получает `VITE_BASE_PATH=/toros/`; все изображения, шрифты и маршруты учитывают этот префикс. `404.html` поддерживает прямые ссылки на SPA-разделы. Проверенная ссылка публикации фиксируется в отчёте после завершения развёртывания.
